# LumaTime

> **A beautifully minimal fullscreen timepiece designed for deep focus.**

LumaTime is a distraction-free productivity clock built around one idea:

**Less interface. More focus.**

It combines a realistic flip-clock experience with a stopwatch, timer, and Pomodoro mode — all inside an intentionally minimal interface designed to stay out of your way.

## ✦ Why LumaTime?

Most productivity tools add more UI, more dashboards, more statistics, and more things to look at.

LumaTime does the opposite.

Open it, enter fullscreen, and you get a large, precise time display with almost nothing else competing for your attention.

It's designed to work particularly well as:

- A fullscreen desk clock
- A study timer
- A Pomodoro timer
- A coding-session timer
- A workout timer
- A minimalist productivity tool
- A secondary monitor timepiece

## ✨ Features

### 🕐 Time

- Uses your computer's local time
- 12-hour and 24-hour formats
- Optional seconds display
- Large flip-clock presentation
- Automatic responsive scaling

### ⏱ Stopwatch

- Precise stopwatch functionality
- Start / pause
- Reset
- Lap recording
- Millisecond display
- Timestamp-based timing for better accuracy

### ⏳ Timer

- Hours, minutes, and seconds
- Start / pause
- Reset
- Large flip-clock countdown
- Visual completion indication

### 🍅 Pomodoro

Built-in Pomodoro workflow with customizable:

- Focus duration
- Short break
- Long break
- Number of sessions

The interface remains intentionally minimal instead of turning the Pomodoro mode into a productivity dashboard.

### 🎨 Custom Appearance

Customize the visual experience with:

- Background color
- Digit color
- Digit glow intensity
- Brightness
- Flip animation intensity
- Clock size

The default theme is intentionally simple:

**Black background + white digits.**

### 🌌 OLED-Style Glow

Adjust the subtle ambient glow around the digits.

The glow automatically follows the selected digit color, allowing the clock to range from completely flat to a soft illuminated/OLED-style appearance.

### ⛶ Fullscreen

Designed to be used fullscreen.

Press:

`F`

to enter or exit fullscreen.

### ⌨️ Keyboard First

LumaTime can be controlled almost entirely from the keyboard.

| Key | Action |
|-----|--------|
| `F` | Enter / exit fullscreen |
| `Space` | Start / pause |
| `R` | Reset |
| `L` | Record stopwatch lap |
| `1` | Time |
| `2` | Stopwatch |
| `3` | Timer |
| `4` | Pomodoro |
| `Esc` | Close settings |
| `,` | Open / close settings |

### 🫥 Distraction-Free UI

The controls automatically fade away when they aren't being used.
